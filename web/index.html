COMMAND HOOKS

Choose the operation boundary.

Completion correlation and syscall-exit gating run on the Linux host that issues the command.

CommandHostOperation wrapper
The exact synchronous wrappers must exist in your patched kernel. Generic command mode uses the configured opcode, queue and masks; asynchronous worker and guest-internal commands are outside this gate.

What an armed hook means

The daemon reports READY only after attachment succeeds. Selecting a host or saving an IP does not establish that eBPF is loaded.

The gate records the issuer when a submission matches the command and controller. Completion uses the saved request identity, even on another CPU. A completed checkpoint is a test-cycle result; migration success and data integrity require separate verification.
